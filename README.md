# Lecto

Aplicació web de lectura i seguiment pedagògic.

## Publicar amb GitHub Pages

1. Puja `index.html` a l'arrel del repositori.
2. A GitHub, ves a **Settings → Pages**.
3. A **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la branca `main` i la carpeta `/ (root)`.
5. Desa els canvis.

GitHub generarà una URL pública per obrir l'aplicació.

> Les dades dels alumnes no es guarden al repositori. L'aplicació utilitza accés privat i sincronització amb Supabase.
